# 🚀 Modern Responsive Registration Form

A modern, professional, and fully responsive registration form built using **HTML5** and **CSS3**. This project features a premium UI design with glassmorphism effects, gradient backgrounds, smooth animations, and mobile-friendly responsiveness.

## 📸 Preview

A clean and attractive registration form with:

* Modern Gradient Background
* Glassmorphism UI Design
* Responsive Layout
* Professional Form Styling
* Interactive Hover Effects
* Mobile, Tablet & Desktop Support

## ✨ Features

* 🎨 Modern UI/UX Design
* 📱 Fully Responsive Layout
* 🔒 User Registration Form
* 🌈 Beautiful Gradient Background
* 💎 Glassmorphism Effect
* ⚡ Smooth Hover Animations
* 🖥️ Cross-Browser Compatibility
* 🧹 Clean & Organized Code

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)


```text
index.html
```
